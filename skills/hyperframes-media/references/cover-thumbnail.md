# Cover / Thumbnail Revision Rules

Use this reference when Cathy asks to revise a social video cover, thumbnail, title image, title text, subtitle text, or top/bottom blurred text area.

## Source of Truth

Treat the latest approved cover image or screenshot as the source of truth.

Do not choose a new frame, new subject, new crop, or new composition unless Cathy explicitly asks for a new cover design. If she says "这个封面上改", "这个封面得留着", "标题改成", or "底下字幕换成", edit the existing cover.

## Preserve by Default

Preserve these unless Cathy explicitly names them:

- central visual frame
- existing main title card
- subject placement and crop
- dark overlay mood
- top/bottom blurred background bands
- caption box placement and style
- approved color language and typography scale

If the center cover title says `Not Every GTM Channel Deserves Your Time` and Cathy says it should stay, keep it intact and only revise the surrounding text areas.

## Text Rules

Use Cathy's wording exactly. Do not polish, translate, normalize punctuation, or replace terms.

Keep punctuation exactly as provided. Example:

```text
硅谷 toB 公司，如何GTM？
```

Color only the words Cathy explicitly named. If she says "硅谷变成橘色", color only `硅谷` orange unless she separately asks to keep a broader prior style.

When she asks for bigger text, increase size within the existing text area. On 1080 px vertical covers, keep at least 40 px horizontal margin.

## Default Cathy Cover Style

For 3:4 vertical podcast/interview covers:

- canvas: `1080x1440`
- top: blurred/darkened source-frame band with large Chinese title
- center: original interview/title-card frame, preserved
- bottom: blurred/darkened source-frame band
- subtitle: existing semi-transparent black rounded box when present
- accent orange: `#ff580f`
- Chinese font: macOS `STHeiti Medium.ttc` or closest available CJK font

## Workflow

1. Locate the latest approved cover image or the frame matching Cathy's screenshot.
2. Edit from that image/frame, not from a different candidate frame.
3. Refresh only the text region being replaced.
4. Preserve untouched cover text and main visual elements.
5. Save a new versioned output file.
6. Inspect the generated image before replying.
