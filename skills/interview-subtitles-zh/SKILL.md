# 访谈中文字幕与转画幅

以用户指定的最终视频为时间轴基线，翻译并添加中文字幕；保留已批准的剪辑、镜头、速度和声音。Cathy 的英文访谈默认保留英文，**英文在上、简体中文在下，各一行**。仅改 skill 时保存规则与预设，不自动重导当前视频。其他用户、纯中文口播或明确要求替换英文时按本轮需求处理。

## 先锁定当前视频与方向

记录实际输入文件、时长、帧率、显示尺寸、旋转与像素宽高比、现有字幕是否已烧录，以及最新批准版本。视频尺寸按 `宽×高`；比例按 `宽:高`：**横版 16:9 / 4:3，竖版 9:16 / 3:4**。把最终像素尺寸和方向写清楚，不继续沿用“横版9:16”之类口头混称。

方向已能从明确措辞、实际文件和前文判断时直接说明采用值。若用户明确要求“横版”但不确定3:4还是4:3，按横版4:3；只有方向仍无法判断、且会改变构图时才问一次。没有要求转画幅时保留原画幅。封面的3:4不代表正片也必须3:4。

本期可复用的横版基线见 [Cathy 双语4:3预设](assets/cathy-bilingual-4x3.json) 和 [Scott 实际成片案例](references/scott-case.md)。这是从完整16:9画面加上下补边得到的4:3，不是裁掉左右人物来填满。其他源比例先实测，不把横版坐标套给竖版。

## 中文字幕放在哪里

中文与英文水平居中，组成稳定的上下两行。中文的顶部由**英文背景框的实际底边 + 固定间距**决定，不凭屏幕底部百分比猜位置。量最宽、最高的字幕及姓名卡/资料页，固定整片锚点，避免随字数上下跳动。

对于本期1920×1440：完整1920×1080画面位于 `(0,180)`；英文框约 `y=1091–1175`，中文框为 `y=1184–1258`，间隔9px。中文仍位于原画面最下沿，**不在新增的底部黑边中**。新增上下黑边各180px。不要拿早先“中文在英文上面”的版本作默认。

源片已有烧录英文时，保留它，只加中文；不要重复画一遍英文、盖英文来造双语或把中文放上方。先检查英文下方是否能容纳中文、且不遮脸或重要资料。有空间则采用上述位置；无空间时保留人物完整，使用补边区或回可编辑工程统一排双语，不静默缩字、拉伸或裁去人物。SRT能记录上下顺序，不能单独保证播放器中的精确位置，成片需要实际渲染验证。

明确另做竖版3:4时重新规划：完整主视频等比置于画布中，已有英文随画面保留；中文可以放在主视频下沿之后的补边/虚化区，不贴整个画布底边。这个位置与4:3默认不同，应保存单独预设。辅助计算与参考命令见 [版式、翻译与验证](references/layout-and-verification.md)。

## 每种语言各一行

“各一行”表示同时最多一行英文和一行中文，合计两行；不把“单行字幕”误解为只准出现一种语言，也不让中文自己换成两行。长中文先忠实、简洁地翻译，再按真实语义和已核对词时拆成相继出现的单行。保持全片字号一致，不用个别缩字或极窄字距掩盖溢出。

中文采用固定预设中的黑体、白字、直角黑色半透明底板。背景随文字宽度变化，左右内边距、行高、顶部锚点固定；先实测全部cue的字宽与字形覆盖，再看实际导出。字体缺失或缺字明确处理，不静默替换。封面的站酷快乐体不自动用于长篇字幕。

## 翻译与时间轴

优先复用与当前成片核对过的英文字幕或逐词稿，不因只加中文而重转写整段。先抽查开头、中段、结尾、重排和重复引用处，确认旧SRT与当前视频匹配；不同封面时长、删剪或速度会改变映射。旧工程的“+1秒”只是个案，不能通用套用。

翻译先读相邻句理解完整意思，再分配到cue。保留数字、否定、条件、不确定语气和事实完成状态；产品、人名、职位沿用用户纠错与核对表，不把 maintain、计划收购、完成收购等升级。减少无意义填充的中文直译，但不能借翻译改写原声含义。避免单独闪现“你”“因为”“我觉得”等碎片；必要时在相邻英文cue中持续显示同一句完整中文，记录对应范围并避免重复淡入。

句子拆分或合并时以实际词区间重新定时；无须对全部cue重新识别。真实停顿留白，不平均分配句长、不统一盲移时间、不把中文显示到下一位说话者。英文烧录且中文cue需要进一步细分时，英文保持原有显示；双语SRT按两种语言的边界并集生成，保留同一段英文，不叠加重复事件。

## 交付与检查

输出独立视频、中文字幕SRT和英文在先/中文在后的双语SRT，保留源文件；项目记录版本、精确尺寸、画面位置、语言顺序、字体、字号、坐标、alpha与时间轴来源。

中文SRT按 `--max-lines 1` 检查；双语SRT按 `--max-lines 2` 检查，并额外核对每种语言恰好一行及英语在先。复用现有 [SRT检查器](../hyperframes-interview/scripts/validate_timed_srt.py)，按各自字体分别检查两种语言的宽度，不能用一个字体的宽度结果替另一种语言背书。最终视频检查DAR/SAR、没有压扁或裁人、字幕不重叠、不越出安全区、首末cue和真实停顿。

纯字幕/画幅修改保护当前音轨与倍率，优先音频stream copy；核对完整音频与最后一句，不能因视频帧数上限或`-shortest`漏掉尾部AAC包。无法直接复制时记录必要转码并核对同步。新增全片编码做完整解码，视觉检查覆盖提问、回答、name card、章节、全屏资料、最长字幕和最后一句；说明抽查范围，不把几张截图称作全片逐帧审核。
