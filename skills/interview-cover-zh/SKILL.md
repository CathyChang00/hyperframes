# 中文真人访谈封面

把真实人物、品牌字标和中文标题组成一张能在手机缩略图读清的封面。中文是独立版式，不是把英文标题换成汉字；保留已批准的人物、文案和组件，只调整本轮指定项。

## 选择正确流程

按最终主标题的语言选择，不按用户用什么语言发消息选择。主标题是中文、夹有 OpenClaw 等英文品牌字标时用本技能；英文主导封面使用现有[英文封面与选图流程](../hyperframes-interview/references/cover-workflow.md)。中英都要时，分别建立两个版式与批准记录，共享源照片，不相互覆盖。

语言与画幅独立判断。用户说“竖着的 4:3”且上下文明确要竖版时，说明按宽:高 **3:4** 执行；真正横版 4:3 或 16:9 仍按要求。不要把中文一律做成竖版，也不把英文横版坐标硬缩进竖版。

被明确指定的其他模板优先。例如“人物抽象背景封面”有自己的构图与安全区，不能因为同为中文而换成本技能的真人照片样式。

同时调用 design-taste-frontend 时，采用其字体、层级、留白、品牌一致性与保留式改版原则；这里交付的是静态真人封面，不引入网页框架、动画、深浅色切换，也不为了生成视觉资产而重画已选人物。

## 开始前锁定四件事

用一句话说明这次是在做新设计还是保留构图的局部修订，然后读取当前批准版本。已有答案直接沿用，不把下列项变成审批问卷。

| 决策       | 至少记录                                                         |
| ---------- | ---------------------------------------------------------------- |
| 人物与画幅 | 原图或原片帧定位、已选调色、宽高、是否双人、批准的缩放与前后层次 |
| 文案       | 精确文字、标点、各行、主次层级、必须同一行的短句、强调词         |
| 视觉       | Logo 原资产、字体文件及字重、字高参照、文字位置、背景与渐变      |
| 批准状态   | 当前采用文件、用户选择依据、受保护项、仍在比较的项               |

用户说“还是这个版本”时，以其指向的实际文件为准。**最后生成的文件不等于最后采用的文件**；一次组件认可不等于整版获批，中途负面评价也不覆盖后来的明确回选。

## 真实人物与双人关系

优先使用用户选中的真实照片或原片帧。只有缺少可用底图时才补选帧；选图和全局调色可按[现有封面流程](../hyperframes-interview/references/cover-workflow.md)执行。已批准的人物区域在后续文字修改中保持不变。

同一张双人照中间空隙太大时，可以先裁掉无用空隙；用户要求人物更靠近或独立前后层次时，用原图透明抠图、等比缩放和平移。受访者可以更大、略在前，主持人靠后且仍有独立轮廓。检查肩膀、手、帽子和身体交叠，不制造搭肩、捶背、肢体粘连或不真实接触。不要为了挤近而拉伸人物、生成新脸或改表情。

文字修订不重新抠图；人物右移确认后，换字体不能悄悄把她移回。保留无字底图和透明人物层，避免在已压平的旧文字上涂背景。

## 中文文案与层级

新文案从访谈证据与观众关心的冲突中选信息，不逐词翻译英语封面。先确定“最有辨识度的身份或品牌”与“发生了什么”的主次，再安排字号。身份、完成时态和数字不能因为追求吸引力而升级；本期批准文案不能变成下一期事实。用户已给精确标题时原样保留，若出现新的证据冲突再明确指出，不自行改成另一句。

用户要求副标题单行时，固定这一约束，优先选合适字宽的字体并微调字号或字距；不偷偷拆为两行、不机械压扁汉字、不删词来凑。实在无法兼顾手机可读性时，说明具体冲突再提出改短文案或换行。主标题仍是视觉第一层。

顶部沿用官方品牌组合与批准的采访身份信息，不重复打一遍已有字标，也不自动补回已删除的底部职务、账号或装饰线。变色只作用于批准词；所有同一行的颜色分段共用一个文字基线。

## 字体与中英视觉尺寸

先看品牌字标的实际形状：粗细、字宽、倾斜、圆角与不规则程度，再找中文搭配。不要只看字体名称，也不要把“更活泼”理解为越卡通越好。原字标略有童趣时，可试有少量个性的中文展示体；用户嫌跳跃时向稳定结构、适度圆角或较克制的字形收敛，而不是轮流随机换字体。

更换字体时控制变量：文案、人物、字高目标、版式锚点、强调色和背景沿用批准状态，让用户比较字体本身。先内部比较少量有明确差异的候选，交付最合适的一版；用户要对比再给并排图。字体变化带来的宽度差异要实测，不凭字号猜。

要求中文与英文等高时，比较**可见字面高度**，不是字体字号、行框或 Logo 整图高度。字母旁的龙虾等吉祥物、透明边、额外装饰均不算入字母高度；下伸部分是否计入，以用户指定的字母/大写高度参照为准。Logo 等比缩放，中文选相应字号，不拉伸字标。

具体测量与复用命令见[字面尺寸、基线与渐变](references/type-and-layout.md)。字母 ROI 需从实际资产确认，不能把“裁掉左边 30%”当所有品牌的通用算法。字体文件缺失或不支持所需汉字时明确处理，不静默替换成系统字体。

行间距按可见边缘量。若用户要求等间距，记录 Logo 可见底边至主标题可见顶边、主标题可见底边至副标题可见顶边；字号改变后重算位置。用于**字高匹配的字母区域**与用于**避免碰撞的整个 Logo 边界**是两件事。

## 字标与中文共用连续背景

黑字字标压在深色衣服上时，可在背后加柔白衬底；白色中文与橙色强调词则需要更深的底。将这些需求设计为一条从字标背后浅色、经过灰色、到副标题背后深炭灰的连续过渡。检查整张图，避免独立白牌接一块黑板、字边一圈白光，或无文字区域也被抬成横贯全幅的亮带。

衬底用足够大的柔边融入照片，保留适量原照片的模糊明暗，让上下连贯。末行强调词后方按实际可读性加深，不把整片下方压成没有层次的纯黑，也不以“通过对比度数字”代替观看。已批准的渐变在字体比较中锁定。

## 交付前看两个尺度

检查全尺寸和目标平台近似缩略图。3:4 封面可用 375×500 检查：脸是否清楚、双人关系自然、字标与中文重量协调、主次分明、单行要求成立、强调词可读、标点和斜体没有裁切、渐变无硬断层。数字校验可发现字高/边距问题，不能替代视觉判断。

导出实际 PNG 与 JPG，回复展示图和可打开的文件链接。采用后记录精确文件及其 SHA-256、批准依据、字体文件/字重、源素材、人物变换、字高与间距、颜色和渲染配置。改字体不自动改视频、重导成片或将封面插入片头；需要绑定视频封面时按[封面交付表面](../hyperframes-interview/references/cover-workflow.md#默认封面不等于片头视频)另行执行已授权动作。
