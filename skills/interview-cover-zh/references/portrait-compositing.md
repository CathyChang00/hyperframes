# 真人素材与双人构图

人物边缘不干净、要求保留电脑或手肘、调整前后/高低关系，或抱怨腿部太黑时读本页。先修当前真实素材，再调整构图；字体变化不触发重新选脸。

## 分开保存真实素材和封面处理

保留一套可复用的人物素材：原片路径与帧时刻、批准姿态/表情、干净 RGB、未加封面渐隐的 alpha、透明人物层和来源记录。若修补了身体局部，记录每块真实来源与映射；封面使用的底部淡出、压暗、位置和缩放另存，不能烘焙进唯一的人物母版。多次缩放从母版重新采样，避免上一版继续缩小导致模糊。

用户已确认“建模”是清晰原图与精细抠图素材时，交付这些素材即可。补充多个原帧能帮助修好头发、衣服、手和电脑，不意味着需要训练人物模型或生成替代脸。

优先复用已选原帧；当前图像素不足、字幕压住肢体或边缘无法修复时，再有针对性地检查本机已有原视频。可把同一人的真实清晰局部配准到批准姿态；不要因为另一帧更好抠就未经说明替换脸、表情或整个人。动作、光线或透视接不上时换修补来源，不能强行拼合。

## 抠图合格才进入位置微调

检查原尺寸局部和浅/深两种底色，最后回到实际背景与缩略图。重点不是只有头发：

| 部位                           | 常见错误                                   | 处理与验收                                              |
| ------------------------------ | ------------------------------------------ | ------------------------------------------------------- |
| 头发、衣袖                     | 白边、背景残留、边缘过硬或糊成一圈         | 用真实轮廓细修；保留自然细发，避免连续亮边和大面积羽化  |
| 手指、手肘、电脑边框           | 指头缺失、身体被误删、物品断边             | 对照原图恢复真实像素；完整物件不能靠渐变藏掉            |
| 手臂与身体、电脑上沿之间的空隙 | 字幕字形被分割模型当成人物，留下白字或黑框 | 同时检查 RGB 与 alpha；删除真正负空间，别把手腕一起擦掉 |
| 修补接缝                       | 肤色突然变亮、腕部断裂、袖子形状跳变       | 校准同人真实来源；在自然纹理处融合，回看整体姿态        |

不要通过让另一个人压住缺损、把人物缩得很小、或用黑色块覆盖来宣称抠图已完成。原素材真有截断时，记录截断范围，并在最终构图里自然收尾。

## 用可见对象定义距离

“重叠少一点”通常是在要求可辨认的独立轮廓，并非指定像素面积百分比。先从当前请求提取约束：电脑四边、手肘最外沿、帽檐、肩膀或另一只手必须可见。将物件圈成多边形，人物边缘使用 alpha，而不是用整个透明 PNG 的矩形判断距离。

记录缩放的参照版本。例如“比 V3 缩小12%”是 `V3_scale × 0.88`；不是“缩成原图的12%”，也不是“让两人重叠12%”。能由上下文确认时直接执行并记录；无法区分且会显著改变结果时再简短澄清。

新构图先确定合理体量与左右位置。用户只要求高低错落时，保持既有尺度和左右关系，单独试垂直位置；请求两个高度就给两个明确档位。选中后锁定高度，仅当本轮仍要求靠近时再沿水平方向收紧间隔：上移会改变电脑与嘉宾肩膀相遇的位置，因此需要重新测遮挡，不能沿用旧的横向极限。

如果嘉宾还需向画面中间移动、电脑又已经刚好不被遮挡，可以将两人整体平移，保持相对间距，以主持人的肘部不出画为上限；这是边界条件，不要求每次都移到贴边。不要为让嘉宾居中再次遮住电脑。没有必须露出的物件时不凭空添加此约束；边缘留量按当前要求与实际展示判断，不固定全片11px。

任何位置变更后都看肩手关系，避免像搭肩、捶背、粘在一起或一人从另一人身体里长出来。错落感可以来自有限高低差和体量差，不必用大片身体遮压。

## 检查可见对象与画面边缘

`scripts/composition_metrics.py` 只测几何，不修改图像。依赖 Pillow 与 NumPy，优先使用已有运行环境。配置里的图像路径相对配置文件解析，图层按从后到前排列：

```json
{
  "canvas": [1500, 2000],
  "layers": [
    {
      "id": "host",
      "image": "host.png",
      "scale": 1.0,
      "translate": [0, 0],
      "require_inside": true
    },
    { "id": "guest", "image": "guest.png", "scale": 1.0, "translate": [0, 0] }
  ],
  "protected_regions": [
    {
      "id": "laptop",
      "layer": "host",
      "polygon": [
        [100, 700],
        [600, 650],
        [580, 900],
        [120, 930]
      ],
      "max_occluded_pixels": 0,
      "max_outside_pixels": 0
    }
  ]
}
```

上面的尺寸、点位与人物变换仅示范结构，运行前换成实际资产。多边形使用其所属人物原图的像素坐标，覆盖整个物件及边框，不只圈中间屏幕。每组点明确标出源图或最终画布坐标，不能把案例中的 `laptop_polygon_canvas` 直接填进本工具；简单缩放平移时按 `source_x = (canvas_x - tx)/scale`、y同理逆变换，并对照源图复核。`require_inside` 只对需要完整在画内的图层启用；正常半身裁切不自动判错。

```bash
python3 /path/to/interview-cover-zh/scripts/composition_metrics.py composition.json --output geometry-report.json
```

检查在画布裁切之前计算，否则已切掉的肘部会被误报为安全。报告包含每层可见边界、四边距离、画外像素，以及每个保护区被前景层遮挡或出画的像素。默认 alpha>16 测外轮廓、alpha>64 判前景遮挡，报告记录实际阈值；透明头发和羽化处仍需肉眼判断。`0` 遮挡只证明给定多边形没碰上前景，不能证明多边形圈对了、RGB没有被字幕污染或整体自然。

## 先判断是压暗还是人物消失

用户说“腿太黑”时，分别查看干净 RGB、原始 alpha、封面专用 alpha 和合成压暗层。人物可能已在 alpha 中提前淡掉；此时只减浅黑色背景不会恢复身体。

若原图有裤料而封面没有，恢复对应真实像素的透明度，让电脑或手下面有连续的身体支撑，再在素材实际结束处缩短并柔化收尾。若 alpha 完整、只是遮罩太黑，则调整局部压暗层。人物上的压暗层和人物背后的背景压暗层分开处理；物件的柔和提亮区随物件移动，避免一块固定亮斑留在旧位置。

末端过渡要覆盖真实截断，不能变成水平硬切，也不能刷出灰雾或灰色矩形。电脑边框、手指不能跟着裤腿渐变提前消失。没有用户的对应要求时，不把生成的身体当作真实原帧延长；若用户已明确要求补腿或发丝，按下一节执行。两人的明暗和下半身露出程度要在整图里协调，不因主持人在后面就把她整片压黑。

## 用户明确要求的局部生成修复

原帧缺失下半身、发丝已切直，而用户明确说“生成自然的腿”“补发丝”时，使用可用图像编辑能力做局部修复。沿用已获得的同范围授权，不把技能的真实素材优先原则变成额外审批门槛；服务调用仍遵循当前工具约束。本期允许生成某人的裤腿，不等于下一期可以随意生成人物。

输入无文字底图与精确遮罩。只补指定区域，例如黑色裤料的自然坐姿/膝腿、外轮廓发丝；保留真实脸、眼镜、表情、手、电脑、上衣以及已采用文字。必要时在生成后把这些保护区域从原图合回，不能只相信模型提示“保持不变”。新增发丝不能包一圈浅色光晕，裤腿必须和已有腰腿及椅子连接，不能多长出手脚或改变人物接触关系。

保存原图、生成结果、遮罩、提示词、模型/服务模式和最终合成步骤。生成区域可能有1–2px位移或色温变化；先按未改的邻近纹理局部配准，再做色彩/梯度融合，最后只在指定区域合回。电脑套下沿、手指边缘、裤腿边和头顶背景是优先检查的接缝位置。

遮罩是保护边界，不应被融合函数悄悄重写。对可能就地修改数组的API传副本（例如OpenCV seamlessClone），调用后核对原遮罩；检查脸部和授权区外是否仍为原图像素。因为配准和边缘融合需要扩展极少量边界时，单独记录，而非放开整张生成图。

先补出连续身体体积，再做逐渐增加的底部散焦。虚化保留衣料明暗和膝腿轮廓，电脑/手的保护边界单独处理；不要用强虚化掩盖一条水平截断，也不拿一块放大的椅子纹理冒充腿。PNG预览和手机缩略图都看，生成区域仅作本次修复，不覆盖唯一的原人物母版。

## 人物与署名发生冲突时

人物尺度、高度和横向位置改变后，重新检查电脑、手、肘和署名。底部平台安全区独立锁定，不能为了让署名离电脑更远就把姓名向下推过点赞线。先调整安全区内的对比度或位置，必要时按当前授权协调人物；未要求改变人物时不要擅自缩人。UI几何按[平台避让](editorial-photo-layout.md#平台避让按真实截图测量)核对。

“上移40px改成10px”描述相对于旧构图的控制量，先按同一参照版本更新，再报告实际头顶/帽顶差。Photon此项最终参数10px，实际原alpha头顶差约32px；两者不是同一个量，不能写成所有人的固定10px头顶差。

## 固定组件，保存采用状态

文字比较锁定人物、颜色和背景；人物位置比较锁定已选字体层、照片资产、表情和尺度，除非本轮明确改这些项。可以用 SHA-256 检查源资产，用图像差分检查应保持不动的区域；不能在移动人物后要求其旧位置像素仍完全相同。

保存当前基准图、变更范围、素材路径/哈希、scale、translate、图层顺序、渐变与保护区，以及 PNG/JPG。没有用户确认的候选标为待选；明确选择某一版后，从该版继续，不从最后生成的实验版继续。完整图和约375×500缩略图都需查看，重点确认头手轮廓、电脑支撑与边缘、末端过渡、标题可读性。
