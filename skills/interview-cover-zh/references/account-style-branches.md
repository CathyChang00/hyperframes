# Cathy 账号风格：按内容选择表达

仅在用户需要跨类型、全账号比较时读，作为背景资料。当前发布重点是口播与访谈视频的封面／发布标题配对，优先[主副标题与发布标题的互补关系](cover-title-pairing.md)。不因标题任务研究口播表达、继续回看旧图文或覆盖当前批准的文案、字体和版式。

## 依据与优先级

2026-11-11 复盘扩展到主页全部 245 张卡片，按 note ID 去掉 2 次置顶重复，得到 243 条记录；其中 241 张封面可读取，2 张原始图片链接不可用。逐张对照封面与发布标题，正文只核对了部分，未完整观看全部视频。用户随后明确停止继续查看更早内容，保留这一边界；清单覆盖不等于全部正文或视频已读完。

受限记录不能作为公开发布案例，私密原文只保留在本地核对资料中。相同主题或相同封面的不同 ID 可能是改版、重发，不能当作多个独立偏好证据。OCR 只辅助找字；图片里的字幕、推文正文、招牌和聊天内容不能全部算作作者设计的主副标题。点赞快照缺少曝光、时间和投放条件，不用来证明标题结构有效。

取舍顺序：本轮明确要求 → 已批准版本 → 近期同类内容 → 较早的其他类型内容。历史口头禅、黑底长文、字体和夸张标题都是风格证据，不自动变成新的固定规范。用户当前不喜欢的词，不因旧帖出现过就重新写回来。

## 先判断内容类型

| 内容                    | 第一眼提供什么                               | 封面与发布标题的分工                                     | 不宜照搬到新访谈的部分                               |
| ----------------------- | -------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------- |
| 真人访谈、GTM 复盘      | 可回答的问题、人物判断、具体方法或资源限制   | 封面可先给判断或答案线索，帖子补阶段、人物行动、案例归属 | 不必仿新闻做惊叹号，不只堆嘉宾身份                   |
| 产品实测、使用体验      | 明确产品、实际操作、比较对象或测试任务       | 图片展示界面或结果，帖子交代测试角度与作者反应           | 看起来像测试不代表结论已被证实；不能只喊“颠覆”       |
| AI 新闻、影视二创、meme | 可识别的事件，加上熟悉人物、影视或生活关系   | 封面可以用场景承接笑点，帖子交代事件或改编方式           | 戏仿、合成画面和夸张台词不能升级成新闻事实或访谈引语 |
| 第一人称行业与生活观察  | “我遇到了什么／我原来怎么想／什么改变了判断” | 原照、现场细节或截图承担证据，帖子补地点、反应、比较关系 | 不把个人见闻抹成宏观结论，不制造“所有人都如此”       |
| 截图、聊天、短日常      | 原图里的信息或一个现场瞬间                   | 帖子可以只给一句读图角度，不强加两层大字                 | 不为了统一系列再给原截图加一套同义摘要               |

这些分支帮助选择，不要求每篇强行归成唯一类型；例如真人访谈也可以借生活比喻切入。关键是观看理由连续，下一层确实带来新信息。

## 比固定句式更稳定的四种做法

### 具体动作和限制，比“有洞见”更好用

常见落点是“人力有限”“扩充团队”“办一场 200 人 party”“开咖啡店”“送泡面”“被劝 Pivot”：读者能想象谁正在做什么。标题需要压缩时，优先保留决定问题的限制、动作或对象，删掉抽象包装词。数字要保留单位、对象与上下文，不为吸引人改成更大的口径。

参考：[零经验办活动](https://www.rednote.com/discovery/item/6a26420d000000000e038400)、[送泡面做增长](https://www.rednote.com/discovery/item/69392c98000000001e03abb1)、[人力有限如何 GTM](https://www.rednote.com/discovery/item/6a6048770000000008009c00)。这里只学习原文如何选具体动作，帖子里的规模和效果未经独立验证，不能移植到新案例。

### 熟悉的参照物，解释陌生的硅谷场景

“硅谷人对 YC 的执念，就像考公之于山东人”“旧金山，就是一个大号的朝阳区”等句式，用读者知道的关系解释陌生场景。有效的是对应关系，而非套用地点名称：要说明像在哪里，保留不完全相同的边界。访谈只有材料真的支持这种比较时才用，不能硬造类比。

参考：[YC 与考公](https://www.rednote.com/discovery/item/692381d4000000001e0371ea)、[旧金山与朝阳区](https://www.rednote.com/discovery/item/6a965406000000000e03b400)、[Oakland 与天津](https://www.rednote.com/discovery/item/6a95030b000000000f03a400)。

### 作者的认识变化，也是一种钩子

“才意识到”“我逐渐理解了”“我的反思”把作者放在现场，适合真实体验、观察或复盘；它们不是需要每期插入的口头禅。保留触发变化的具体事情与原先判断，让读者知道为什么现在值得讲。新访谈不应把嘉宾的认识变化写成 Cathy 自己已经经历过。

参考：[Lovable 也是出海团队](https://www.rednote.com/discovery/item/6a167233000000000f03ac03)、[朋友创业后的反思](https://www.rednote.com/discovery/item/6a13b67c000000000f03ac00)。

### 中英混排与口语服务于准确和节奏

AI、Startup、GTM、VC、Pivot、具体产品名可以自然保留，不能为了全中文改得拗口；不为模仿风格生硬塞英文。“薅走”“卷到线下”“才意识到”和少量 emoji 可以表达当期态度，但严肃访谈不默认加“震惊”、大额数字、情绪词或表情。

## 视觉学习的边界

账号存在人物封面、原生截图、现场照片、黑底文字、影视帧等多种形式。它们共同提供的是主题识别和信息分工，不是相同的设计模板。

做现在的中文访谈时，仍优先用户已经选定的“标题在上、人物在中下、底部署名、自然照片延续”及紧凑科技字体；Scott 当期选中的活泼字体继续作为独立案例。不能因为旧帖很多是黑底，就把新海报加回大黑块；也不能从历史截图推导新的固定字号或平台安全区。

设计两层封面文案时，沿用“上面 hook，下面给解答或答案线索”的明确偏好。原始截图或单一现场画面已经表达完整信息时，允许只留一个钩子，甚至不另加文字；信息层数应由内容需要决定。品牌署名不冒充答案，视频逐句字幕不冒充主副标题。

## 把规则用于新一期

先写出本期可核对的事件、动作、限制、判断或数字，再选最适合的观看理由。把封面文案与帖子标题连读：是否围绕同一个问题、是否各有新增信息、是否保留了说话人的归属。若只是视觉修改，以上判断用于发现问题，不授权重写已批准文字。

历史样本帮助理解选题与语言；新节目能否兑现承诺，仍靠本期逐字稿、素材与用户定稿核对。无需为每次简单改字重新遍历整个账号。
