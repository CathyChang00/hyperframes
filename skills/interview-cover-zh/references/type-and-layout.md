# 中文字面、基线与渐变

需要复现字高、排查中英不齐或实现局部背衬时读本页。视觉结果仍由实际封面和缩略图判断，不仅看字号或检查器。

## 字高的三层边界

| 边界                | 用途                 | 不要混淆                               |
| ------------------- | -------------------- | -------------------------------------- |
| 字体字号与 line box | 排字工具的输入       | 不代表肉眼看到的字高                   |
| 中文/字母可见墨迹   | 同高匹配与字重比较   | 不含透明边、行距或旁边的吉祥物         |
| 整个 Logo 可见边界  | 安全区、避让与行间距 | 吉祥物可能比字母更高，不能拿它放大中文 |

先打开透明 Logo 资产，确认真正字母所在的矩形 ROI。若白色背景仍烘焙在图片里，先用可靠方法去底并肉眼检查黑色字没有丢失；不能直接把整张白纸当作墨迹。可见墨迹可统一按 alpha≥128 测量；防裁切另用较低阈值，例如 alpha≥16。记录阈值，避免前后用不同口径比较。

小工具 `scripts/type_metrics.py` 使用 Pillow 与 fontTools，测量实际字体与透明图，并检查字体是否包含所需字符；不生成封面、不替你选字母 ROI。优先复用现有 Python 环境，缺依赖时在项目虚拟环境安装 `pillow fonttools`，不要为了本工具改全局 Python。以下命令从技能根目录运行，或使用绝对脚本路径：

```bash
python3 scripts/type_metrics.py text \
  --font assets/fonts/ZCOOLKuaiLe-Regular.ttf \
  --text '核心开发者' --target-height 150

python3 scripts/type_metrics.py logo \
  --image /path/to/transparent-logo.png \
  --letters x0,y0,x1,y1 --target-height 150
```

第二条的 ROI 必须替换成当前图片的真实像素坐标。TTC 字体用 `--index` 选择实际字重；输出中读回字体名称。缺字会报错，不能把方框替代符当成有效中文。选出字号后，用完整标题和标点重测边界，再导出实际文字层，不能只测无标点片段就假设整行安全。缩放后读 `rendered_letter_height` 和 `target_delta`，不要把目标高度当成实际输出；栅格缩放可能差 1px。

为达到同一可见高度，两个不同字体可能需要很不同的字号；这是正常的。只做等比例 Logo 缩放，不把中文拉宽到与 Logo 外框一样宽。若新字体变得过窄或过重，先重新判断字体是否合适。

## 顶部品牌行占宽

Cathy 的中文 3:4 竖版访谈系列以 Photon / Julie 顶部整行为参照，默认使用 [series-header-preset.json](../assets/series-header-preset.json)。用户明确要求不同嘉宾的顶部整行占比一致，而非复制字号。

先把官方品牌标识、`Interview | 姓名` 与批准的组内间距组成一个透明图层；以 alpha≥16 的整组边界测宽，包含组内空隙，排除外侧透明边、截图白边、阴影与柔光。此处包括完整品牌符号，和匹配中文字高时只测字母 ROI 的规则不同。

```text
target_width = round(canvas_width × 0.876)
scale = target_width / group_visible_width
整组的 x/y 尺度均乘 scale，保留内部比例
```

1500px 宽的封面，目标整组宽1314px；1125px 宽时为986px。输出后再测真实可见宽度，容差为画幅宽度的±0.5个百分点，不把目标值当作实测值。Photon 参照的透明资产宽1314px，alpha≥16 的实际墨迹宽1312px，均落在该范围内。

现有封面只调占宽时保留已采用的左上锚点，人物、下方文案与背景不动。新封面可从左边距5.6%画幅宽、顶边距3.6%画幅高起排；1500×2000时为(84,72)。字高随组的宽高比自然变化，不强求不同品牌、不同长度姓名同字号或同高；不拉伸 Logo、不用加大字距凑宽，也不自行删短姓名。优先从原 Logo 和真实字体重新高分辨率渲染，避免直接放大截图中的压缩文字。

验收同时看整图和375×500缩略图，并记录 `canvas_width`、`header_visible_width`、`header_width_ratio`、锚点、alpha阈值及目标值。局部改版再做差分，确认人物及其他批准组件未变。本比例是中文竖版系列的默认值；用户另给占宽或改成其他模板时按新要求，不自动套到英文横版。

## 颜色分段共用基线

用 Pillow 绘制同一行的不同颜色片段时，所有片段使用同一 `baseline_y` 与 `anchor='ls'`，下一段 x 用字体的实际 advance 推进；支持 kerning/shaping 的排字引擎应按整行完成 shaping 后再着色。不要让每个颜色块按自己的墨迹顶边独立摆放，也不要用不同字号的橙色来假装强调。

```python
x = left
for text, color in runs:
    draw.text((x, baseline_y), text, font=font, anchor='ls', fill=color)
    x += font.getlength(text)
```

“先按同一基线绘制整行，再整体裁出透明文字层”可以保留字体自身的不规则字形，而不额外制造字块跳动。斜体、冒号、中文标点与末字都检查右侧和上下留量。

## 等间距是几何约束，不是固定模板

若用户要求两处可见间距相等，令 `g` 为当前批准间距：

```text
主标题顶边 = 整个 Logo 的可见底边 + g
副标题顶边 = 主标题的可见底边 + g
```

换字体后重测主标题可见底边，副标题随之调整。主标题字高使用字母 ROI 参照；行间距仍使用整个 Logo 的可见边界，防止吉祥物碰到下一行。画幅变化或文字变长时重新布局，不把 Scott 的 56px 写死。

## 从柔白到深灰的一个连续场

对黑字标、浅色主标题、彩色副标题的组合，可以把灰度随 y 连续下降，再混入低频照片纹理。示意函数为：

```text
L(y) = dark + (light - dark) / (1 + exp((y - midpoint) / spread))
```

这只是可调实现。把浅色峰值放在黑字标后，渐变中点避开必须清楚的文字；副标题后的底色更深。上缘以平滑透明度过渡融入原图，左右按图形的实际范围柔化，避免白色横条。需要保留照片感时混入原照片大幅模糊后的低频明暗，不添加与现场无关的纹理。

观察白底黑字、白字、品牌红与强调橙分别落在哪里，不用一个全图平均对比度判断。大标题可参考 3:1，较小文字可参考 4.5:1 的对比度检查，但字体形状、抗锯齿、设备和缩略图会改变感受；用户看不清时以改善结果为准。照片本来已可读、Logo 是浅色或本轮只改字体时，不必套这个白到黑的方案。
