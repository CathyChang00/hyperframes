| 版本ID  | 默认尺寸  | 布局                                          |
| ------- | --------- | --------------------------------------------- |
| en_16x9 | 2560×1440 | 顶部品牌＋Interview＋姓名；底部左对齐英文标题 |
| zh_3x4  | 1500×2000 | 顶部标题；中下双人；底部品牌署名              |
| zh_4x3  | 1500×1125 | 顶部紧凑两行；双人上半身；底部署名            |

## 中文横版4比3

标题按可见墨迹共用左锚；Logo与身份可同排一行，下一行写事件或观点。署名独立定位。人物与字号按横版重排，不等比缩小整张竖图。需要复现时看[Scott横版参数](scott-approved-case.md#横版4比3采用分支)。

## 裁切

横4:3必须交横图，中间安全框不能代替成品。只在用户明确要求竖图兼容横裁时设置中间区域：1500×2000内约y438–1563。

裁切保全标题、字标、脸、署名及指定的手／电脑；不够则回源图层重排，不拉伸整图。只有扁平旧海报时先找原项目，缺关键素材就说明限制。旧1438×2000图可参考构图，但不是严格3:4。

## 导出与核对

各版独立保存，如Guest_en_16x9.png、Guest_zh_3x4.png、Guest_zh_4x3.png。查看缩略图：480×270、375×500、400×300。

按[清单示例](../assets/cover-set.example.json)运行：

```bash
python3 scripts/check_cover_set.py cover-set.json
# 只修改一版时
python3 scripts/check_cover_set.py cover-set.json --only zh_4x3
```

检查实际文件比例、缺版及可选elements边界；不代替看图和平台核验。UI相交／行距用layout_guard.py，方法见[平台避让](editorial-photo-layout.md#平台避让按真实截图测量)。
