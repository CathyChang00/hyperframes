# 封面选图、设计与交付

用于真人访谈选帧、双人拼接、封面标题与 Logo、版本比较及默认封面交付。Cathy 的偏好是个人默认，不是所有用户、画幅或品牌的通用要求；本轮明确参考和已批准版本优先。

## 先确认当前处于哪个阶段

选人物帧 → 无字构图 → 标题文案 → 排版候选 → 局部调整 → 应用到交付。只补尚未完成的阶段。用户说“先看，不要加字”就交无字图；说“先确定标题，封面是 step 2”就先定标题；已经选定并说直接做时继续执行，不把每一步变成必须再次询问的关卡。

从现有项目取最新批准文件，维护简短的决定记录：人物候选 ID 与来源、底图版本、exact title、断行、字体/字重、强调词/色值、Logo 文件、顶部身份文案、底部信息开关、默认封面模式、批准依据。保留上一版与无字底图，避免修改标题时换回未选人物或把已删除的页脚带回来。

## 选人物：让用户能选，而不是替用户定义“最美”

优先从固定双人机位找封面帧；它通常最容易保持两人的比例、光线和真实现场。先粗采样找笑容与转头时刻，再在附近逐帧筛选，分开评估每个人。清晰度或自动打分只用于筛查，不能替代用户审美。

Cathy 此次反复认可的方向是自然微笑、眼睛睁开、表情放松；微笑可以轻露齿，不必只找闭唇。相对正面或轻微转向的候选更有选择价值。避免眨眼、说话中尴尬嘴形、夸张张口、手遮脸、模糊和镜片反光。更正面是一项偏好，不是否定已经选中的侧面微笑；看镜头与看对方都可保留，按表情质量排序。

候选应有明显差异，覆盖不同笑容和头部角度，不拿同一瞬间的十张相邻帧充数。按用户要求给数量，例如初选每人 5 张、只重找 Cathy 时给 10 张；未指定数量就先给足以比较的小组，不默认渲染大量方案。Julie 已选定而 Cathy 不满意时，只重选 Cathy。

每张候选使用稳定、不可复用的 ID，画廊提供脸部/上半身预览及可打开的完整机位帧。旁边标源文件和源时间，不把剪后时间当原片时间。新一轮沿用未冲突编号或加批次前缀；保留旧 ID → 源帧映射，不能让用户说的 `C12` 在新版页面指向另一张脸。

用户选中后，把“喜欢的特征”与“选中的文件”分开记录。Photon 的 `J1、C4、C14、C12` 是该片的反馈锚点，最终组合为 `J1 + C12`；不能只有 ID 没有源图，也不能把这些 ID 当新项目预设。

## 固定机位的双人拼接

两人的最佳表情可以来自不同时间。用同一个固定机位的全帧，保持原有左右位置、相机几何、身体比例和光线；在静态墙面、窗框或桌面等背景区对齐、羽化。不要沿脸、头发、手或身体做明显接缝；检查背景重复、错位、双影和桌面道具的连续性。

按两人的视觉重量与外侧留白平衡构图，减少无功能的下半身、椅子和笔记本面积，为标题留空间。不要为了填满版面拉伸人物或裁坏头顶、下巴、手势。真人画面默认不生成新脸、不换表情、不做瘦脸或未经要求的美颜；已批准人物区域在后续纯文字修订中保持不变。

用户要无字预览时，交完整横版底图和方便比较的预览；不附加 Logo、标题、姓名、账号或装饰。已选组合不因换字体而重新拼接。

## 标题：先把英文说顺，再排版

Cathy 的这类横版访谈封面默认英文。标题以最终访谈的论点或观众收益为依据，保留观察范围；可以是编辑概括，但不能伪装成逐字引语。先检查单复数、GTM 的修饰关系及语义，再冻结原文。

Photon 批准文案为 `What AI Startups Should Learn from Crypto GTM`，不是此前的 `What AI Marketers Can Learn from Crypto`。这是该期标题，不是所有 AI 访谈的套用句式。用户给了精确文字或只让改颜色/位置时，不擅自重写措辞、大小写和标点。

要求 5 个版本时，使用同一批准底图和标题做有区别的排版方向，不把“5版”变成五组人物或五个未经确认的新标题。清楚编号，支持整图比较及单张查看；大字行宽、字体气质、层级或渐变可有区别，人物、文案和品牌身份保持一致。用户选了第 2 版字体，后续沿用它，不再随机换字体；认可某个组件不等于认可整版，其他布局仍按最新反馈修改。

## Cathy 真人横版封面的排版方向

主标题所有行向左对齐、使用足够厚的字重；尽量在两行内按语义断句，行首共用同一锚点。重要的是手机缩略图也能读清，不能为塞进长句把字体缩得很小。标题位于画面下部，删除底部姓名/职务/handle/横线后，把腾出的空间交给主标题，而不是保留空页脚。

标题和人物脸之间留呼吸空间；必要时用从下部逐渐加深的暗色渐变提高可读性，别用大面积不透明黑板吞掉人物。两人脸部保持清楚，避免阴影或文字跨过五官。其他画幅重新排版，不把 16:9 坐标硬套到 3:4。

顶部用官方图形标志 + 官方 wordmark 组成品牌锁定组合，再配 `Interview ｜ <Full Name>`。例如 Photon 的官方 lockup 已包含 `Photon`，后面只加 `Interview ｜ Julie Chen`，视觉读作 `Photon Interview ｜ Julie Chen`，不要重复打一个 Photon。公司 Logo 用用户提供或已核验的官方素材，不能用普通字体仿画 wordmark。

顶部组合留安全边距，字号小于主标题，按用户选定位置整体移动；“往下／再往上／小一点”每次只做可见的小幅调整，记录基准与变化，不逐次累计成失控偏移。旧的 `PHOTON / INTERVIEW` 黑色胶囊、`Interview ｜ Photon CMO` 和底部人物资料不自动复活。

强调色只作用于指定词，字号、字重、基线与同一行其他文字保持一致。用户说 Pollo 橙时，Photon 本轮已核验值为 `#FF4900`，只给 `Crypto`；不要换回旧项目 `#FF5812` / `#ff580f`，也不要擅自把 `GTM` 一起染色。

### Photon 批准样式的可复用起点

仅在复用这张 16:9 封面或明确沿用其风格时参考，之后仍实测行宽和边距：

| 项目               | 已批准值                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| 主标题             | Optima Bold，左对齐；第一行 `What AI Startups`，第二行 `Should Learn from Crypto GTM`                    |
| 主标题颜色         | `#FCF8F0`；仅 `Crypto` 为 `#FF4900`                                                                      |
| 1920×1080 逻辑画布 | 标题字号约 124px、左边距 88px、两行文字顶部约 y=767 / 912；原渲染另加约 2px 同色字形描边增重             |
| 顶部               | 官方 Photon lockup，`Interview ｜ Julie Chen` 使用 Avenir Next Demi Bold，约 60px；lockup 左上约 (88,29) |
| 实际交付           | 2560×1440 PNG、1280×720 JPG；检查约 480×270 缩略图                                                       |
| 底部资料           | 无姓名、职务、账号、分隔横线                                                                             |

字体不可用时先找气质与宽度相近的候选并实际渲染；不要声称用了未安装字体，也不要自动下载来历不明的字体。预览检查字重、每行左锚点、强调词、顶部品牌比例、下边距和脸部无遮挡。

## 默认封面不等于片头视频

分别记录和验证下列交付表面：

| 表面              | 完成证据                                                                        |
| ----------------- | ------------------------------------------------------------------------------- |
| 独立封面          | 实际 PNG/JPG，像素尺寸及批准版本一致                                            |
| 本地播放页        | video 的 poster 指向批准图；首次打开/刷新且未播放时实际可见，无自动播放抢掉封面 |
| MP4 内嵌封面      | 支持时以 attached picture 写入；提取后与批准图核对，不能只看命令成功            |
| 平台/播放器缩略图 | 在目标平台单独设置并验证；部分播放器只取首帧，文件内嵌不保证自动识别            |
| 占时长片头        | 只有明确要求封面停留/作为开场画面时才剪入，并重算音画、字幕和章节               |

用户说“放到最终版，default 为封面”，默认更新封面文件、播放页 poster 和可支持的文件封面，保留原片头节奏。交付时用一句话说清“播放前显示封面，播放后直接进入访谈”，不要说成封面已经占据视频前几秒。

新一版名牌、字幕或开场导出后，沿用批准封面；更新播放页的视频地址与下载链接，同时保留 poster。重开实际页面检查封面、播放与当前文件版本，不能仅交一个旧文件名的预览页。修改文件封面时尽量直接复制音视频数据，不为封面重新编码全片。
