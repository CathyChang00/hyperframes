# Cathy 个人访谈固定预设

仅用于 Cathy 的个人 16:9 访谈。最新要求和项目已批准的局部例外优先；其他用户、公司节目及不同画幅不自动继承。新节目从[数值预设](../assets/cathy-interview-16x9.json)初始化项目配置：将 JSON 与其引用的水印 PNG 一起复制到同一项目目录，或直接引用 skill 中的预设；只复制 JSON 会丢失相对路径资产。记录预设 ID 和明确覆盖项；后续渲染、字幕与检查读取同一份配置，不在多个脚本中重新猜值。现有节目局部修订时保留已批准效果，不为了套新预设重做无关部分。

## 字体、标题与水印

数值预设以 1920×1080 为设计画布。同宽高比输出将完整图层等比缩放；竖版或其他比例重新排版，保留单行等明确要求。字体使用本地有许可的 Optima Bold 与 Arial，不随 skill 分发字体；缺字体时明确报错，不能静默换细字体。

章节标题用短、可口播的问题或话题名，例如 `What is Paradigm?`、`Why buy a university?`。不重复叠公司名、小眉题和同义副标题。固定粗字、米白色与局部羽化背衬；不把整块画面压成黑底。先缩短不必要文字、选择不挡人的位置，再考虑经记录的版式例外；不逐题随意缩字号。品牌字标可替代标题中的同一个词，避免标题和角落再出现一遍 Logo。黑色字标需要浅色局部背衬，白字需要适度暗部，分别处理，不能一起加黑。

水印直接复用[批准的透明 PNG](../assets/cathy-twitter-watermark-1080p.png)，按 JSON 的尺寸和位置覆盖全片，包含 teaser、资料和片尾。此资产继承 Photon 的背景深度，同时保留 Scott 版本已认可的字形和放大尺寸；不要误回退到 Photon 原来的小字号。JSON 保存原色与 alpha，不能从截图里混合后的灰色反推不透明度。资产 hash 可防止无意改样式。

`scripts/render_cathy_overlays.py` 读取预设生成透明水印、单行字幕、普通章节图层，可供 FFmpeg 使用，也可作为 HTML 渲染的像素参考。标题中的特殊 Logo 合成仍由项目处理，不把 Scott 的龙虾、Columbia 坐标或问句写入通用模板。

```bash
python3 scripts/render_cathy_overlays.py watermark --out /project/layers/watermark.png
python3 scripts/render_cathy_overlays.py subtitle --text "What is Paradigm?" --out /project/layers/subtitle.png
python3 scripts/render_cathy_overlays.py chapter --text "What is Paradigm?" --out /project/layers/chapter.png
```

脚本需要 Pillow；字体路径可在项目预设中显式覆盖为同款字体。所有输出是设计画布上的 RGBA 图层，不会修改视频。正文字幕最大宽 1640px 现统一用于新建 teaser 和正片；旧 teaser 的 1620px 验证上限不要求无故重排。

## 字幕、姓名条与资料

字幕每次只显示一行。长句按原声词级时间拆成连续、语义完整的短字幕，保留全部原词；不换成两行、不临时缩小字体、不平均分配每词时间。用现有 `scripts/validate_timed_srt.py` 的 `--max-lines 1`，并传入预设的字体、字号、padding 和宽度，查看最宽字幕的实际导出帧。

Teaser 不放受访者姓名条；正片介绍主持人和嘉宾时保留各自姓名条。姓名与 handle 属于每期数据，账号没确认就核实，不复用上一期嘉宾。默认 teaser 接在正片开头交付一个完整视频；明确要求独立 teaser 时再单独交付。

全屏新闻、图片、X 资料卡每段最终显示时间不得超过 4 秒，淡入淡出计入。按最终帧率计算 `floor(4 × fps)`，29.97fps 最多 119 帧；慢放后重新限时，不能把 3.97 秒资料图拉成 4.3 秒。缩短资料覆盖后回到采访机位，主音轨继续。资料过密就选关键句和局部，不延长一张大网页让人硬读。相邻重复卡不能用重新编号规避上限。

Logo 优先透明或原生底色，紧裁无用留白；原有蓝底等不再加厚白边。组合信息先有主元素，随后在同一构图内补关系：例如主公司位置不变，下方出现 `Backed by …`。动效表达左右对比、因果或公式，不单纯蹦词；不默认加下划线、巨型白框或连续重复同一组 Logo。

遇到“换成这个字标”“字和上一版一样大”“改组合构图”时，按[图形关系与品牌构图](graphic-composition.md)处理实际字高、分组、主元素位置和局部背衬；不只替换一个同尺寸图片框。资料选型与每次出现是否必要见[资料的信息任务](visual-evidence.md#按信息任务选资料避免每次提品牌都放同一个-logo)。

短 X 内容直接使用真实原帖截图，保留截图本身可见的头像、姓名、完整 handle、原帖日期/时间和 views。截图已提供这些信息时，不另写日期、标题、摘要、脚注或重复署名，也不 paraphrase 原帖。优先调整截图裁边和显示尺寸，让原文可读；不重新绘制平台界面，不补写截图里没有的时间或指标，不拼接另一时间的 views。缺少信息时在内部来源记录中注明，不靠屏幕补字伪装成原帖内容。

长截图先保持可读宽度，再用固定视窗滚动，不为整张同屏缩成窄长条；宽度至少对齐本期已批准的同类原帖。头像、handle、正文、日期和 views 可随滚动分阶段出现，不必每帧同时可见。过密时选意思完整、语境足够的连续原文；不跨段拼句、不删限定词。用户明确指定整张截图时保留其内容范围，通过视窗和停留分配处理；若仍无法在限时内读清，说明取舍，不静默改写或延时。只有确实无法直接展示或用户明确要求时，才做忠实于原文且标为 `原文摘录` 的编辑摘录。全屏截图及摘录仍受 4 秒上限约束，首尾停留与淡入淡出均计入。

画面不重复标注，不等于省略内部出处。从最终时间线生成 `资料出现时间与来源` 与章节表，继续完整记录版本、起止、时长、展示类型、原帖 URL、作者/handle、可核实的发帖日期/时间、观察日期、本地资产及截图证据；缺少字段明确记为未取得。变速后重算，不手动维护另一套秒数。资料来源表可以保留完整链接和核验说明，这些不再作为脚注叠到原帖截图上。

## 配乐与资料动效

Cathy 新节目默认有低音量但可闻的无歌词配乐。teaser 可取同一曲更有起伏的节选，正文更轻；同曲优先但不是强制，也可用两首相容的音乐。已有成片保留批准混音，更新默认值不授权重配。人声优先，音乐只作衬托；音量差、淡入淡出和避让方法见[配乐与对话混音](podcast-production.md#配乐与对话混音)，其中数值是调整起点，不是每期固定验收值。

全屏静态新闻、原帖、网页、海报与图表默认有轻微向下浏览感，即内容缓慢上移；背景、水印和字幕固定。短图可从 1080p 画布内约 40–60px 位移起调，长图优先保证宽度与阅读路径。必要的固定放大只用于覆盖视窗边缘，不用持续 zoom 或蹦词代替滚动，也不能裁掉片名、人物脸或关键数据。已有有效运动的视频不叠加多余滚动；角落 Logo 和章节标题不属于此默认范围。具体方法见[资料滚动与长截图视窗](visual-evidence.md#资料滚动与长截图视窗)。

JSON 中的 `music` 与 `materials.motion` 是供项目编排读取的策略和可调起点，不代表已经完成混音或动画。`render_cathy_overlays.py` 仍只生成静态水印、字幕和普通章节图层；音乐与资料滚动由项目实际渲染流程实现并检查。

## 全片 1.2 倍与交付检查

Cathy 之后新建节目的 teaser 和正文默认均为相对原速的 1.2×，保音高，播放器保持 1×。更新这项默认规则不授权重导当前已批准版本；现片保持其批准速度，只有明确要求修改该视频的速度才重定时。新剪辑从原速主音轨单次变速。已有 1.3× 成片改为 1.2×，时间伸长比为 `1.3/1.2`，音频相对 atempo 为 `1.2/1.3`，不能再直接乘 1.2。优先重用原速剪辑母带；需要保留既有精细剪点而只能处理已变速 PCM 时，记录二次处理并检查听感，不冒充原速重建。

速度变更同步调整字幕、章节、姓名条、资料窗口和所有重复引用，另按最终时间限制资料卡。完整词尾不能为了整数帧数被截掉；必要时尾帧短 hold。沿用已批准剪辑内容，不借调速再次删除问答。

交付前核对配置及实际导出：水印几何与底色不漂移；字幕单行且不截字；teaser 无姓名条而正片有；资料限时；章节和来源表对应真实时间。完整新编码做音视频解码，听审与画面抽检准确说明范围。纯视觉修改保留音轨，倍率修改则检查新的同步，不能沿用旧音频身份通过报告。
