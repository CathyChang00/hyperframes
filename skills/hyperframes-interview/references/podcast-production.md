# 播客制作与原声完整性

用于多机位、收音、截词/异响、变速与交付；技术参数以本项目为准。

## 完整问答与自然口播

先列 `章节 → 主持人问题 → 保留答案 → 案例/边界`；保留介绍、转题、追问、纠正前提的问题，长问题留完整核心与必要条件，不能只留嘉宾。逐人清理重复起句、嘴瓢、自我修正、填充词、无效附和，保留有功能的反应与呼吸。

优先一次说完整的原声，用同步机位/相关资料遮跳切；不将 `like / so / actually` 一概视为口癖，不用配音、重塑口音或改写伪造“native”。专名修正优先取同次回答完整正确版本并查连词/节奏，无法独立则留修正过程。删后检查 `because / and / which…` 等未完逻辑，恢复上下文或完整收束，不用字幕补写。

记录 `片段ID｜speaker｜原文件｜source入/出｜完整原话｜剪辑动作｜输出出现位置`；登记片头/正文重复引用，纠错同步画面、声音、字幕和在线交付稿。

## 关键剪口语义检查

检查 cold open、跨句/段拼接、删问题或纠正前提、移动论证及可能改意的句内微删；普通静音缩短、已可靠审查且未变的片段可复用记录，不按换镜次数审计。

高风险剪口取含问题、限定、后续纠正的连续原声，列剪前上下文、删词、剪后实播原词顺序，不称拼接稿为连续原话。查五项：`many / some / seem / I think / at that time` 等范围限定；`not / but / except / unless` 及后续纠正；主语、群体和指标对象；相关是否变因果、先后是否颠倒；`they / it / those stages` 的指向及答案是否回应问题。

`semantic_reviews` 记录剪口/原句 ID、原片范围、输出版本/区间、剪前上下文、实播文本、结论、证据、reviewer 身份，字段/工具见[修订工作流](revision-workflow.md)。分记代理文本复核、实际听审、用户亲听；关键剪口仍须绑定成片局部核验，文本不证明实播。机器 diff/词表/检查器只标 `needs_review`、缺字段、证据过期，不凭相似度认证保真。reviewer 按上下文决定保留、恢复、重选或待确认；无法核实且可能改意则留完整语境或换安全片段，不用字幕/卡片造原话。另查声学接点和尾词。

## 画面机位与主收音分开选择

用户指定的文件/声道登记为批准基线，切画面不换声；发现缺陷先做同句对照再说明替代。登记各文件时长、分辨率、帧率、音频流/声道、采样率、起始 PTS 及分段录制关系，不凭机位名或文件头同步。

同一 reference 时间对比双方独讲、交叠、安静、异常处的削波、回声、底噪、串音、响度、可懂度，分记仪器分析与听审。双人镜头只是收音候选；双领夹/分轨确认归属，按说话人选清楚通道，留弱回应/交叠，必要时短交叉淡化；不永久等权叠加不同距离/延迟音源或硬门限截回应。

同步映射写清方向，如 `reference_time = scale × native_file_time + offset`，标文件、有效区间、代理起点；在开/中/后及跨文件接缝核查波形、口型与漂移，使原文件、reference、成片时码可互查。

先建连续对白，同句换镜只改视频。“重复/不连贯”先查原声/EDL，区分原话重说、源区间重播、声学卡顿、景别观感；重播才删重复范围，否则保持镜头或移视觉切点，不凭画面删字。换镜不修尾音或语义缺口。

## 截词、漏词与异常声音

编辑以当前成片为基线，调查/补尾回未剪原片，不取已剪 master 下一段。争议点映射原文件并留句前后上下文，按[音频对照](audio-comparison.md)运行 `scripts/make_audio_comparison.py`，生成三段；映射不可靠则标缺口，不用相似句冒充同源。用户自查给原文件位置及其分钟/秒数。

ASR、强制对齐、DTW、波形/口型只辅助定位；零时长 token、低置信边界词须回源，接话或闭嘴不证明尾音完整。区分录制噪声、坏剪口、处理伪影、播放问题；突发声可能覆盖辅音，不整块当非语音删除。

优先同句干净可同步的原声，否则轻处理、同源同响度对照，查移除部分有无语音；固定频段/谐波遮罩、低 RMS、ASR 认词不证明未损人声。无法消噪又保词则保留完整原声/现场声并说明，不截尾/合成；不能听审就提供原速对照并报技术范围。

用户亲听确认原话/噪声原因记为 `user_confirmed`，保留机器原稿，执行稿及字幕用确认内容；这不授权生成声音，也不代表助手听过。补尾先恢复完整源区间，淡化不吞音节，再改画面、字幕及全部重复引用；保留处理前音轨和修复范围。

## 配乐与对话混音

Cathy 新节目默认低音量但可闻的无歌词音乐，其他用户依当前要求；已有批准混音不因 skill 更新重做。teaser 可用较有起伏节选、正文较轻，也可两首相容曲目；不盖辅音、尾词或自然反应。

试混起点：正文音乐比同期有声对白 RMS 低约 18–24 dB，teaser 低约 14–18 dB；同窗口分别测人声/音乐，这不是固定推子或验收阈值。按录音、频谱、听感调整音乐 EQ/duck；加配乐不重新变速、剪词、降噪或压缩批准对白。峰值高先降音乐，确需整体固定增益须记录并保留人声源，不用限制器暗改对白。

保留批准对白、音乐底轨、最终混音，记录来源、节选、音量和交叉淡化。音乐放最终时间轴，不套采访倍率；循环及 teaser→正文检查实际交叉点节拍相位，片尾自然淡出。用来源/许可明确的音乐，保存曲名、作者、源/许可链接、下载证据及必要署名，通常放发布说明，许可要求画内署名时遵守；曲目、私人 sample、本地绝对路径不成为公共 skill 固定依赖。

最终编码音轨检查响度、true peak、削波、首尾长度、同步；对白保留可在无损阶段核验映射及 `mix = dialogue × recorded_gain + music_bed`，不要求 AAC 解码后样本相等。试听覆盖 teaser、正文、循环/交叉点、结尾，记录实际范围；数值及工具报错不能写成已听审，不能听音则留可试听片段并说明。

## 变速与时间映射

仅授权后变速。Cathy 新节目片头/正文默认 1.2×，见[固定预设](cathy-style.md)；批准版保留原倍率，其他用户不自动加速。记录已烘焙/目标倍率，优先从原速生成；1.3× 改 1.2×，相对倍率为 `1.2/1.3`、时长比为 `1.3/1.2`，再套 1.2× 会成 1.56×。保音高，二次处理须记原因和听感检查。

用整数输出帧、有理帧率、半开区间 `[in, out)` 记切点，音频按累计边界换算样本并声明舍入，避免逐段取整漂移。实测长度与收尾，不为凑帧裁非静音尾词；静音补齐/末帧保持须记位置和新增长度。

修改前建 `旧输出区间 → 新输出区间 → 原文件时间 → 倍率` 映射，同步字幕、章节、B-roll、姓名条、问题、播放器总长和重复引用。Cathy 全屏静态资料仍限 4 秒、指定视频上限 15 秒，覆盖后回采访机位，保留下方原声；视频 B-roll 默认独立 1×，见[视频 B-roll](video-broll.md)。预览底片/音轨已烘焙倍率时播放器设 1×。

## 交付与验证

先做覆盖本轮风险的短预览，如尾词接点、姓名条、最宽字幕/资料卡；整片已授权则仅作内部检查，不新增批准节点。封装后查实际输出：

| 对象 | 证据                                                                              |
| ---- | --------------------------------------------------------------------------------- |
| 文件 | 路径、时长、分辨率、帧率、音视频流、旋转/色彩；新全片编码完整解码，局部修订按下节 |
| 内容 | 开头、末句/末帧、变更点、章节接点、关键问题、修复原句全部出现处                   |
| 画面 | 导出帧中的字幕完整且不越界，姓名匹配人物，资料卡可读且实际出现                    |
| 声音 | 最终压缩音轨对冻结原声 master 的局部偏移、句尾/接点及首尾长度，全片相似度不能替代 |
| 版本 | 视频、master、EDL/plan 的身份或 SHA；检查后改媒体须复核受影响范围                 |

报告实际检查与听审范围，以及保留的现场声。交付所需全片 MP4、最终 SRT和预览；来源、机位/收音映射、版本和资料索引留工程内。保留前版，回读实际文件及画面后才报完成；仅有预览或命令成功不代表导出完成。回复给变化、限制和文件。

## 局部修订与验证复用

按封面/元数据、文字/姓名条、画面、声音、时长分类，以最近批准版为输入，记录文件身份、主音轨/声道映射、确认原声区间、允许修改项及需重建层；小改不重复转写、选机位或处理声音。确认的尾词与现场声受保护，字幕/封面/水印修改不重做降噪、裁尾或变速；音频修订检查所有重复引用，总时长相同不证明音轨未变。

旧 ASR/报告与现稿冲突先查当前交付；已授权而未落实的文字纠错应补齐并说明范围，不扩大为声音或结构重剪。只换默认封面优先复制音视频流、更新 poster/attached picture；少量画面可复用干净底片、字幕图集、水印层。局部拼接须保证编码参数、关键帧接点、时间戳和同步兼容，否则正常重渲染。

验证改动窗口及两端接点解码；未改视频的 payload/时间信息与批准版一致；复用音轨数据、时间戳、长度未变并关联新 MP4；帧数、时长、章节、字幕、封面、播放器指向正确。只有对应输入及时间映射未变才继承验证；证据不足就扩大范围，截图抽样、容器整体 hash、退出 0 均不能证明一致。

核查实际成片，不只看 PNG/HTML；更新渲染源、工程变量/元数据、交付链接并保留前版。不伪造编辑器缓存声称已设封面，见[封面交付](cover-workflow.md#默认封面不等于片头视频)。记录继承版本及检查范围，不把局部 decode 写成全片人工看听；只报可理解进展和新版结果，不逐步骤求确认。
