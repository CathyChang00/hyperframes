# 视频 B-roll 选段与合入

用于将指定 launch、demo、街访、活动或社媒视频放入已批准访谈。只改相关画面覆盖，保留原声、音乐、字幕、章节与倍率，不要求重建整片。

## 先看实际视频，再决定用途

逐项登记指定文件/链接；短链接保留原址与解析后原帖，复用本地资产先核来源与身份，不能用同公司另一视频替代指定素材。检查时长、画幅、帧率、音轨、全片概览及候选段实画面，文件名或摘要不能证明含产品 UI。

按可见内容定用途：实际操作解释交互，但旧 demo 不证明当前上线或效果；抽象动画/品牌故事承接愿景，不冒充真实课堂、资产或功能；街访/活动提供场景，不把无声口型或别段表情当同步采访。来源表注明公开演示、概念画面或静音拼接及语义边界，功能、交易、头衔另核证据，不额外给画面加免责声明。

## 以完整过程选长度

Cathy 指定视频每段最多 15 秒，静态全屏资料最多 4 秒；其他项目用当前配置。分类按来源与任务：滚动截图即使导成 MP4 仍属静态；发布视频中的叙事/插画动画不因局部静止退回 4 秒。见[资料限时](revision-workflow.md#资料限时与时序的机械检查)。

先找完整动作或场景：操作发起、反馈到结果，结果不能刚出现就切走；检查源边界，避免出点闪入下一镜头。15 秒不是配额；删无信息等待/重复，不误删 UI 反馈，不靠冻帧、重复、慢放凑长。超长选独立过程或明确拼接；正常帧率转换的重复/丢帧另记。

窗口绑定当前回答的具体句子，不扩大到受保护的提问、姓名条或章节，不延长全片。替换记录旧新区间，从干净底片重建或完整覆盖旧窗口，防止两端漏旧素材。

## 声音、倍率与画面文字分开处理

默认导入时丢弃 B-roll 全部音频流，保留批准采访对白与配乐，不因换底片退回无配乐版；用户明确引用资料原声时单独安排，以导出音轨验证静音。

B-roll 默认原速 1×，source 映射独立于采访批准倍率；音乐也不继承采访倍率。区分源已变速、工程速率和播放器速率。已有运动视频不强加滚屏。

源字幕/口号/UI 与节目字幕分层；避免两套口播字幕同时叠加，优先调整等比布局或选干净区间，必要时只裁非必要装饰字，不裁脸、手势、结果或关键 UI，不涂限定词。保留原生比例、颜色和有意留边，不盲目拉伸。预处理已烘焙则不重复执行，记录 `crop_baked_in` 和裁切参数。节目字幕与 Cathy 水印保持独立固定层，实导帧核 UI 与动作极值。

## 原片、派生文件、成片三层可回查

连续段只记原资产、源入出点、速率与成片区间；跨段拼接/预处理才加派生映射：

```text
用户文件/原链接 → canonical 原帖、作者、原资产 SHA
source ranges / fps 或实际 PTS → 派生区间与资产 SHA
crop_baked_in / 裁切 / playback rate → 最终 [in_frame, out_frame)
source audio discarded / 用途 → 导出检查
```

VFR 用实际 PTS，不用名义 fps 冒充精确时间。对外来源表写原片真实区间；派生从 0 秒开始仅为工程调用，标“静音画面拼接”，不冒充连续引语或同步机位。

复用现有 EDL/manifest。`interview_project.py` 只检查分类限时、原声关联与证据绑定；其 `checked` 不验证源区间、派生映射、裁切或混入素材声音，须另查工程与导出。

## 局部验证与交付

复用[局部修订](podcast-production.md#局部修订与验证复用)与[边界检查](revision-workflow.md#滚动与配乐修订的证据)。查每段前、首、中、末、后一帧及跨源接点；动作/快速转换/文字变化加局部播放，静帧不等于完整观看。边界有争议时从已知起点解码选精确帧，不能凭快速 seek 邻帧判漏帧。

复用音轨核数据与时间戳；素材静音、批准配乐保留、字幕不变分别检查。更新实际渲染及完整来源表，保留未改记录，不以新增清单覆盖全片来源。按要求交完整视频或局部预览，不新增确认关卡，也不因更新 skill 自动重导成片。
