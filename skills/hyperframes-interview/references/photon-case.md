# Photon 访谈复盘：如何使用这个案例

以下来自 Cathy 在 Photon 访谈制作中的连续反馈，截至人物名牌 V19 与封面 V7 确认，用来解释剪辑判断。人物、话题、时长、倍率、候选 ID 与素材数量属于该项目，不能变成其他节目的硬要求；可复用的个人封面偏好见[封面工作流](cover-workflow.md)。

## 可复用的纠错

| 反馈与问题                                        | 下一次的处理                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------- |
| “主持人的问题呢”                                  | 一开始建立问题—答案覆盖，产品介绍与转折保留原提问；修正同步到在线稿与视频             |
| Cathy 有重复起句、嘴瓢，希望表达自然              | 两位 speaker 都精修，保留真实原声；不靠新 VO 或口音处理重造表达                       |
| 先双机位，后来允许有价值的第三机位；收音有问题    | 画面与音轨分开挑，逐声道核验收音，第三机位按提问/反应价值使用                         |
| Julie 单人镜头残留 Cathy 肘部；双人镜头留白失衡   | 检查入点、出点和动作极值，问题边界再逐帧定位；不把单人机位自动当合格特写              |
| 想更平视                                          | 优先选源机位与合适构图；不把裁切冒称真实改变拍摄角度                                  |
| Twitter 资料少、长时间单镜头，开头 demo 又太长    | 按具体话题补图文和活动视频，分散到正文；demo 只保留关键动作与结果                     |
| 谈 Hermes 合作、ABG CMO、不同组照、游艇与 go-kart | 分事件找原帖，不能一组素材顶替多个时间点，也不能只找视频                              |
| 浏览量和粉丝量是人物的重要叙事                    | 核原帖/主页指标并给阅读重点，记录观察日期，不混用不同帖子的数值                       |
| 帖子卡长 URL、`X PRODUCT DEMO` 丑且冗余           | 正片用作者、handle、日期、简短标题；完整链接保留在来源索引                            |
| 想把字幕黑底改半透明                              | 改实际渲染图层并查看成片；仅修改 SRT 或样式文档不算完成                               |
| “最美”选图不合审美；Julie 可用，Cathy 要重找      | 保留满意人物，只重选另一人；优先自然微笑、清晰眼神，补相对正面候选；稳定编号可回源    |
| 两个人分开选出满意帧，再拼成固定双人机位          | 先交无字合成图；背景区拼接，保留人物真实像素与相机几何，不生成新脸                    |
| 底部姓名栏浪费面积、标题字体不好看                | 删除姓名/职务/账号/横线页脚，主标题下移，沿用已选字体并加粗、全行左对齐               |
| 顶部 Photon Interview 丑，后续多次小幅移动        | 使用官方图形和 wordmark；固定 `Photon Interview ｜ Julie Chen`，只改用户指定位置/大小 |
| Crypto 换 Pollo 橙                                | 精确改指定词为 `#FF4900`，保留其他文字、人物与字号                                    |
| 不保留 Host、Guest，姓名与 Twitter 两行           | 同时更新工程和实际烧录名牌；见[姓名标签](visual-evidence.md#姓名标签)                 |
| “这版没有封面吗”                                  | 区分默认 poster、MP4 内嵌图和占时长片头，验证并用一句话说明点击播放后的行为           |

## 冷开场的最终选择

最初尝试过数字型 launch；Cathy 后来明确要求围绕 Crypto 背景与 X 营销、注意力的观点选片头。先给候选和可回看的原片，等她说“可以剪吧”后替换主片。28 秒被认为太长，单句又太短，最终保留能完整成立的观点与一层落点，核心关键词尽早出现。

不能把“很多在 X 上做得强的营销人有 Crypto 背景”扩写成“所有 AI 从业者都来自 Crypto”。强度来自原话选择与节奏，不来自夸大范围。

## 原声事件与人类确认

用户亲自查看原片后确认原句为 `they have crypto working background`，并确认大声瞬态来自关门。此前过强处理伤到了句尾，V15 撤销该处理、从原始文件恢复完整区间，片头和正文一起更新；现场关门声保留。ASR 漏词不再被用来否定用户听审，报告没有冒称助手听过或噪声已消除。

## 本项目最终参数（仅作案例）

片头 1.3×、正文 1.2×，分别从原速素材处理；最终约 16 分 02 秒。用户先要求 20 分钟以内，随后允许 30 分钟以内，因此不存在必须填到 20 分钟的下限。成片有 45 个资料窗口、28 个来源，这些是结果，不是下一期配额。

V18 删除了开头 `Crypto experience in X marketing` 说明标签；不能因为 cold open 规则提到语境卡而把它加回来。若原声已能交代主题，就不默认再做同义标题或音效包装。

V19 名牌各两行：`Cathy Chang` / `Twitter @cathychang00`；`Photon CMO ｜Julie Chen` / `Twitter @0xJuliechen`。无 Host/Guest 眉题。另有独立常驻右上水印 `Twitter @CathyChang00`。本片对白及可见卡片不带本项目明确排除的品牌信息；16:9 英文字幕使用约 60% 黑色底板不透明度。其他姓名、品牌、账号或新样式以新项目确认值为准。

## 封面选择与最终交付

先展示每人 5 张人物候选；Julie 候选被认可，Cathy 重找 10 张，并补了更正面的选择。Cathy 明确喜欢 `J1、C4、C14、C12`，最终选择 `J1 + C12`；更正面的要求没有取消后来明确选中的 C12。选定后先交无字拼接图，再做 5 个标题版，继而沿第 2 版字体细修，不能把这些中间动作视作每一期必须重复的审批链。

源双人机位 `photon-镜头2-1.MP4` 中 C12 为约 1592.2573s／帧 47720，J1 为约 1985.2833s／帧 59499；这些只用于复现该片，不能当成输出时间。合成保留 Cathy 左、Julie 右，在静态中央背景对齐与羽化，未生成/美颜/变形人物。标题改为 `What AI Startups Should Learn from Crypto GTM`，两行 Optima Bold 左对齐，下移占用删除底部资料后释放的空间。

封面 V7 顶部为官方 Photon lockup + `Interview ｜ Julie Chen`，标题只把 `Crypto` 变为 `#FF4900`。无底部姓名/职务/handle/横线。交付 2560×1440 PNG、1280×720 JPG，默认播放页展示批准封面，MP4 附带相同图；点击播放直接进入访谈，没有追加停留片头。这次“封面仍在吗”的追问应促使交付说明更明确，而不是擅自添加几秒封面或改动已批准 cold open。
