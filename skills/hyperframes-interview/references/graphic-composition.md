# 图形关系与品牌构图

用于访谈中的关系动效、组合 Logo、标题内 wordmark、品牌资产替换和局部明暗背衬。字体、字幕、水印与默认尺寸继续读取项目批准配置；Cathy 项目见[固定样式](cathy-style.md)。这里补充如何作构图决定，不重新定义一套样式。

## 先明确关系，再决定分组与动画

先用一句话写出原声要表达的关系，标出完整对象、判断和不可拆短语，再选择形式。并列比较用同级并列；组合条件与结果可用公式；公司与投资方用主从/背书关系；先后过程用顺序。不要只从逐字稿抓几个名词分别放大。

分隔符、行距和相对位置都会表达关系。例如某期的 `OpenClaw Side Project｜No Moat`，左侧是一个完整对象，右侧是对它的判断；不能把 OpenClaw 与 Side Project 分成两个对立对象，再把 No Moat 挂成模糊脚注。完整短语保持连续阅读，分隔符只放在实际关系边界。这个例子说明分组方法，不是下一期的固定文案。

先完成一个独立可读的静态终态，再按原话的次序揭示元素。动效要让观众更容易理解新增关系，不能只让词轮流跳动。最终停帧应能表达完整的一条信息；动画不改变主语、否定、范围或因果，不能将嘉宾的条件判断包装成普遍事实。无需额外强调时不加下划线、重复标题或装饰性标签。

用户只要求先看一张图时，先交对应语境的静帧，不直接更新视频；已授权应用或整片制作时，静帧是内部检查步骤，不新增审批。静态关系成立后再检查动画中间态，避免元素尚未出现时短暂读出错误结论。

## 用最终组合规划位置，让信息逐步补齐

先为最终完整组合预留一块合适空间，再安排主元素先出现、关系词和次元素后出现。主元素的锚点、尺寸与对齐方式在揭示过程中保持稳定，不从第一段左边跳到下一段右边；字幕、脸部与手势安全区一起考虑。

比较对象保持同级、同一列或同一基线；背书/归属关系作为主元素的附属层级靠近它。比如出现投资方时，可在已在场的公司 Logo 下补 `Backed by …`，不必把公司、关系词、投资方拆成横贯人物的三块独立标签。最终排布依画面空白和人物位置决定，不把某期“都放右边”变成所有项目的固定方向。

同级资产按可见图形的视觉重量校准，保留各自比例；不通过拉伸把长字标和方形图标塞成相同盒子。出现新元素前后各看一帧，确认主元素没跳位、关系词没有变成孤立的小标签，观众能顺着同一路径读完。

## 替换 wordmark：保持可见字形大小，不拘泥旧图片框

Logo 文件尺寸、透明边距和实际字高不是一回事。替换标题中的品牌词时，先裁无用外边距，测量实际文字墨迹边界或大写字高，与上一批准文字比较；不能因为新图多了图标或大片留白，按旧图片框 fit 后把字缩小。

把品牌图标、wordmark、前后文字和标点作为一个标题组合处理。先保持批准的字号与层级，再整体移动、按语义换行或扩展组合宽度。允许标点超出旧文本框，不等于允许出画布安全区；标题不能碰水印、字幕或人物脸。若 logo 已替代句中的品牌词，不再在旁边重复打一遍同名文字。

用户给精确文案时保留文字、大小写和标点；“只换图”不授权改问句。“和上版一样大”优先指实际看见的字，不是沿用一个会缩小字形的容器尺寸。检查完整画面和字标近看两种尺度，确保整句层级没有因换资产漂移。

## 透明背景、品牌原生底与局部对比

预处理先区分无关外部空白、品牌原生有色底、字形内部留白和图案高光。原生蓝底配白字的标志可以直接保留蓝色矩形，不再外套厚白卡。用户要求去白底时只处理背景，保留白色字形、图案眼睛和内部高光；不要把全部白像素一律透明化。对透明边缘与细字做实际合成检查，避免白边或抠掉内部细节。

只有直接叠加确实不清楚时，才补足够小的局部背衬。黑色字标后用浅色、白字后用适度暗色；混合黑红字标与白色句子分别处理，不给整组统一加黑，也不把整张画面洗白。背衬范围跟随对应字形，边缘羽化，并保护脸部和现场亮度。背景明暗变化时检查代表性的亮帧、暗帧和动作帧，不能只用一个静帧证明整段可读。

对用户的“太黑、白边太大、字比上版小”做局部改动：分别调整背衬的范围/强度、外边距、实际字高。保留其他批准元素，避免用全画面压暗、整组缩放或换字体解决局部问题。

## 交付前的针对性检查

一次只核查本轮相关风险：静态终态关系是否正确；揭示前后主元素是否稳定；新字标实际字高是否匹配；透明处理是否损伤内部细节；背景变化时混合深浅字是否可读；资料、字幕、水印与脸是否冲突。核查实际导出与过渡帧，不只核对 CSS 或 PNG 尺寸。几何或脚本检查不能替代关系理解与画面可读性的审阅。
