# 画面、字幕与社媒证据

在用户要求三机位、特写、平衡构图、减少单人长镜头、补 Twitter/X 图文视频、突出浏览量、调整字幕或添加个人水印时读取。

## 景别与构图

先看各机位的代表帧，再定义双人、主持人、嘉宾和特写。两机位已够用时不为数量硬塞第三机位；第三机位用于有价值的提问、反应、手势或遮挡跳切，保持同一时间的真实动作与表情。

真正的特写要改变景别，突出面部和情绪；只切到一张仍很宽的单人画面不算。优先从高分辨率原片裁切，检查最终清晰度、头顶与下巴、重要手势、另一人的胳膊/肘部和半个人体侵入。不要为了裁掉肘部又切掉说话人的脸。

双人镜头按两人的视觉重量、外侧留白、座位与视线平衡，不能让主持人一侧无功能地空出大块空间。姓名条配对应人物的单人镜头或清楚的双人镜头，不在别人的单人画面下介绍另一人。

用户觉得俯拍、显得佝偻时，优先选更接近平视的源机位，再调整裁切、头部位置和水平线。裁切不能真实改变拍摄高度，不声称已经把高机位变成真正平视；透视微调须检查脸和身体是否变形，不能未经授权重造人物。

## 让资料跟着谈话走

先列视觉内容地图：`成片话题/原话 → 具体事件、产品或观点 → 原始来源 → 图片/视频 → 插入位置 → 能说明什么/不能说明什么`。产品合作、争议文章、活动、反馈等出现时，优先用该事件本身的资料；资料不只集中在开头。

用户说画面“干”或单人镜头过长时，补充有信息的窗口：原帖关键句、合作宣布、产品操作、活动现场、不同组照、相关反馈。视频和静图可混用；不把所有静图排除，也不让一条 demo 长时间占据开场。没有匹配资料时，用同步主持人反应、双人镜头或有意义的特写承接，不靠无关图片填满画面。

每个窗口只承担一个可读的信息点。demo 优先选实际动作和结果，删等待、输入停顿与重复画面；活动视频保留能说明现场规模/互动的动作。图片按阅读量停留，不能一闪而过。5–8 秒可作为一段动作的初始试剪范围，实际长度由信息决定；没有用户配额时不强制“每N秒插图”或固定总秒数。

用户指定多个时间点、两组不同照片或不同活动时逐项登记覆盖，不把同一张图重复当两组，也不拿同一公司的另一场活动代替当前事件。涉及负面观点时，不把无关人物照片放上去暗示其涉事。

## 查原帖与指标

先核验人物、公司和 handle 的对应关系。通过可用连接器或浏览器查个人与公司账号，再按产品、合作方、日期、活动关键词和回复链找原帖。搜索摘要只作线索；核原帖作者、日期、媒体内容、完整上下文与可见指标。

每个引用保留最小来源记录：

```text
source_url / author / handle / posted_at / event_date（若不同）
asset_path / asset_type / evidence_path / observed_at
edit_in / edit_out / editorial_purpose / semantic_limits
metric_kind / display_value / exact_value（可见时） / metric_source
```

浏览量与粉丝量要分别取证。帖子的 views 必须属于正在展示的同一原帖，followers 属于对应主页；点赞、播放、曝光和浏览量不互换。显示值与精确值分开，原页面只有 `1.6M` 时不能凭空生成精确计数；访谈自述也不能冒充截图上的当前数字。记录观察日期，无法核实的值不显示。

当谈话的重点正是传播成绩时，可以放大真实 views/粉丝量，让观众读得到；普通资料帖无需都包装成“爆款”。指标、日期、身份与原帖内容不可互相拼接成一条伪造帖子。

## 资料卡保持简单

参考布局：`姓名 · @完整handle · 日期`，加一个简短主题标题，例如 `Hermes on iMessage`，主区域交给原帖图片或视频。避免把长 URL、`X · PRODUCT DEMO` 等内部分类标签、重复作者信息和多层装饰塞入画面。原始链接保留在工程索引/交付稿；用户或素材授权要求可见署名时遵守。

优先展示真实截图；需要放大关键句或指标时可裁切或做明确的编辑信息卡，保留来源并忠实呈现，不伪造平台界面或更改原帖意思。资料视频通常保留采访主音轨，确需资料原声时再有意混入并检查音量。

姓名卡使用本轮确认的完整姓名与 `@完整handle`，不要把主持人的全名截成昵称，不从旧项目自动附加公司或 CTA。被排除的品牌要检查对白、字幕、name card、片尾与引用截图等所有观众可见/可听表面；技术来源索引保留真实出处。

## Cathy 个人水印

Cathy 的个人项目默认使用原文 `Twitter @CathyChang00` 作为个人标记，保留空格、`@` 和大小写。它不是雇主标识、嘉宾署名或片尾 CTA；不替代各人的姓名条与资料来源。此偏好不适用于其他用户，也不自动套到公司或客户项目；用户本轮明确要求的文案、位置或关闭水印优先。

在画布右上角安全区放独立的全片覆盖层，从首帧到最后一帧的每一帧持续显示，包含 cold open、采访、图片、视频 B-roll、章节卡与片尾。保持静态、低调但清晰可读，不带入场/退场动画或音效，不随镜头和场景切换消失，也不能被全屏资料层或转场盖住。

按实际画幅给水印保留独立空间，与一行/两行字幕、姓名条、原帖账号、浏览量和章节文字分开；避免遮挡人物与演示操作。可以用轻描边、阴影或小面积半透明底保证明暗画面上的对比，不把水印做成另一块抢眼标题。其他资料与右上角水印冲突时，调整资料和片内信息的布局以避让，不临时移动或隐藏水印，也不靠某一帧碰巧留白。

同时更新工程预览和实际导出，把水印烧入最终视频；单改封面、HTML 文案、字幕文件或导出元数据不算完成。仅添加水印时保留已批准的时长、帧率、音频内容与音画同步。先确认全片覆盖层的时段、可见性与层级覆盖所有帧，再查看最终导出的首帧、中段、最后一帧，以及图片/视频 B-roll、章节切换和双行字幕的代表帧，抽样核验全文可读、无碰撞；首中末仅是抽样检查，不代表水印只在这几处出现，也不能单凭抽样声称已逐帧验证。核对 `ffprobe` 的时长、帧率和音轨信息。

## 字幕与资料的共同安全区

字幕语言和画幅取当前要求；英文原声字幕不能擅自润色为说话人未说过的句子，用户确认的纠错保留依据。语义分组、稳定锚点、最多两行、零重叠适用于不同版式，但字号与安全宽度要按输出画布实测。

Cathy 本次认可的播客方向是白字、简洁直角、黑色半透明底；可从约 60% 不透明度开始，背景仍应能透出。已有批准样式或新参考优先。不要把旧 3:4 中文模板的坐标、40px 字号和实黑底硬搬到 16:9 英文节目。

在放帖子、指标和姓名条之前预留字幕区域。导出实际帧，查看最宽原句、双行句、名字/账号、指标与背景对比，必要时整体移动资料或卡片；不能依赖“预览看起来有空间”。改文字后同时更新实际烧录 PNG/图集、HTML 与 SRT，避免只改文稿却继续用旧字幕图。
