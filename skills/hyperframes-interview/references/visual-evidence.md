# 画面、字幕与社媒证据

内容规划涉及事件/产品资料，或需调整机位、构图、社媒证据、字幕、姓名条与水印时读取。Cathy 个人 16:9 项目以[固定样式](cathy-style.md)为准：静态全屏资料最多 4 秒，用户提供或指定视频可至 15 秒；本页不覆盖该预设及当前批准例外。

## 在内容阶段建立资料计划

整理 transcript 时同步标记需要展示的事件、操作、合作、文章、人物关系和传播成绩，先写入内容地图，再核原帖与资产、安排画面。只改封面或名牌时复用有效计划，不重启无关研究。

每项关联稳定的原句/内容单元 ID 与原片时间，成片入出点由剪辑方案生成：

```text
内容单元 / 连续原话 / 原片时间 / 待呈现信息
原帖 URL / 作者、handle / 发帖与事件日期 / 指标及观察日期
自述或已核实 / 本地资产与证据 / 可用动作或关键句
叙事作用与不能证明的内容 / 覆盖位置 / 查找、核实、使用状态
```

与[项目配置](revision-workflow.md)的 `materials` 关联，区分待查、找到未核实、已核实、资产可用、已排入、导出已确认、未使用及原因。缺资料则记缺口并继续可独立剪辑的部分，不用别场活动、他人帖子或无关照片替代。用户指定不同时间点、组照或活动时分别建项。

优先覆盖关键论点的证据、操作、结果和上下文，再检查长单人镜头是否缺信息变化；不按固定插图频率、总秒数或数量填满。

## 景别与构图

先看各机位代表帧，再定义双人、主持人、嘉宾和特写；按本轮要求及素材价值使用第三机位，明确要求三机位时登记实际位置。备用机位与反应镜头必须来自同一时刻，不借别段表情伪造回应。

按发言功能选画面：关键主持人提问须看得清提问者，回答以嘉宾为主，互动可用双人或同步反应。Speaker 归属依据核实的逐字稿和现场信息，不能按画面猜。长答案在观点、例子、情绪或手势变化处换景；短完整句可保持，不机械限时。重组跳切先接顺声音与语义，再用同步机位、适度 punch-in 或相关资料承接；只切画面时保持主音轨，见[制作参考](podcast-production.md#画面机位与主收音分开选择)。

特写须真正改变景别，优先裁高分辨率原片；检查清晰度、头顶/下巴、手势及他人肢体侵入。双人镜头按视觉重量、留白和视线平衡；姓名条对应人物单人或清楚的双人镜头。检查入点、出点和动作极值，异常再逐帧定位，不能用代表帧证明整段安全。

俯拍显得佝偻时优先换接近平视的源机位，再调裁切与水平线；裁切不能改变真实拍摄高度，透视微调不得扭曲脸和身体。审片重点看关键问题与最长单人答案，不为镜头数量打断表达。

## 让资料跟着谈话走

将可用资产绑定为 `原句/内容单元 → 事件或观点 → 原始来源 → 资产 → 成片窗口 → 能说明什么/不能说明什么`。重剪或变速后重新映射，不沿用旧秒数。资料分布跟随实际谈话，不集中堆在开头；无匹配资料时用同步反应、双人或有意义的特写。

每个窗口只承担一个可读信息点。demo 保留操作、反馈与结果，活动视频保留能说明规模或互动的动作，删无信息等待和重复。Cathy 静态全屏最多 4 秒，指定视频可至 15 秒，淡入淡出计入，变速后重算；不硬切所有素材为 4 秒或强凑 15 秒。视频详见[选段与合入](video-broll.md)。缩短 B-roll 只改覆盖窗口，主音轨继续；用户另要求压缩内容时才改问答与后文时间轴。

明确提及作品、人物、地点或产品时核对实体和版本，优先用户指定图，缺少再找可靠来源；保留片名、重要脸部与必要语境，不暗示原话没有的合作或背书。负面观点不得配无关人物照片。指定多组照片或不同活动须分别覆盖，不能重复同一组交差。

### 按信息任务选资料，避免每次提品牌都放同一个 Logo

| 信息任务                   | 优先资料                                           |
| -------------------------- | -------------------------------------------------- |
| 认出公司、产品、人物       | 当前批准 Logo、标志或人物照片                      |
| 看到发布、收购、合作等事件 | 对应原公告、报道、原帖或现场图                     |
| 理解机制或操作             | 对应界面、demo、流程或原有示意图                   |
| 理解数据与关系             | 有来源、单位和时间范围的数据图，或忠于原话的关系图 |
| 认出作品与案例             | 对应版本的海报、封面或案例素材                     |

Logo 不能充当事件证据，同名实体不可混用；身份、头衔、年份与数据口径不能靠转写猜。可靠来源与口述不同时记录差异，不用错年份新闻或更高头衔迁就原话。相对时间范围绑定截止日期，不以示意上涨线冒充真实数据。

同一资料再次出现须有新比较、证据、必要回顾或用户指定用途，跨段重复也检查；再次提公司名不自动放 Logo。Cold open 预告与明确复现可保留。只维护本轮实体的轻量记录：`实体/来源 ID → 批准资产 → 预处理 → 使用位置/角色/用途 → 替换范围`，关联现有清单，不另抄时间表。“全部替换”检查标题内 wordmark 等所有位置；局部指定按范围执行。组合图形见[品牌构图](graphic-composition.md)。

## 查原帖与指标

先核人物、公司与 handle，再通过连接器或浏览器按产品、合作方、日期、活动与回复链找原帖。搜索摘要只作线索，核原作者、日期、媒体、上下文和可见指标。最小来源记录：

```text
source_url / author / handle / posted_at / event_date
asset_path / asset_type / evidence_path / observed_at
edit_in / edit_out / editorial_purpose / semantic_limits
metric_kind / display_value / exact_value（可见时） / metric_source
```

Views 必须属于展示的原帖，followers 属于对应主页；点赞、播放、曝光和浏览量不互换。`1.6M` 不推算精确值，访谈自述不充当当前截图数字；记录观察日期，未核实值不显示。只有传播成绩是谈话重点时才放大指标，不把普通帖子都包装成爆款，不拼接指标、日期、身份与内容伪造原帖。

## 资料卡保持简单

短 X 内容直接用真实原帖截图，保留其可见头像、姓名、完整 handle、日期/时间和 views；不另加标题、摘要、日期、脚注、重复署名或 paraphrase，不补原图没有的指标。优先调裁边与尺寸，完整出处留内部来源表；授权明确要求可见署名时遵守。

长图用下节滚动视窗保阅读宽度。过密时选语境完整的连续原文，不跨段拼句或删限定条件；无法直接展示或用户明确要求时才做忠实且标为 `原文摘录` 的编辑摘录。指定整张图须保留内容范围，优化视窗与停留，仍难读则说明取舍，不静默改写、缩成窄条或延时；Cathy 全屏截图和摘录仍最多 4 秒。

工程索引与 `资料出现时间与来源` 保存原帖 URL、作者/handle、可核实日期、观察日期、指标证据、本地截图和实际成片区间，缺字段记未取得。被排除品牌须检查对白、字幕、姓名条、片尾及引用截图等全部可见/可听表面，技术来源索引仍保留真实出处。资料署名、姓名条和个人水印分别处理。B-roll 默认弃用全部自带音轨，沿用批准对白与配乐，详见[视频 B-roll](video-broll.md)。

## 资料滚动与长截图视窗

Cathy 全屏静态资料默认缓慢上移，形成向下浏览感；只动资料层，背景、字幕和水印固定。已有有效运动的视频、角落 Logo 和章节标题不继承。短图可从 1080p 下约 40–60px 位移起调，按文字、脸和数据位置修正；固定 overscan 可防露边，不用动画 zoom 代替滚动或裁掉关键信息。

长图先定可读宽度，再定固定视窗与浏览路径：至少匹配本期批准同类原帖的实际可见宽度，无参考可从画布宽约 75% 起调。不能整张 `contain` 缩成窄条；视窗避让水印与字幕，超高内容通过上移浏览。

作者、handle、正文、配图和原有日期/views 可依次出现，不要求始终同屏，也不在外面重写一套。允许首尾 hold；hold 与淡入淡出均计入 4 秒。内容过密选完整连续片段，不高速扫完整页或延长。

记录原图路径/SHA、视窗位置尺寸、显示尺寸、起止偏移、首尾 hold 和最终帧区间。查看导出首中末帧及窗口前后边界，核宽度、方向、原文覆盖及固定层；hold 内重复帧正常，不要求每帧 hash 不同。验证复用见[修订工作流](revision-workflow.md#滚动与配乐修订的证据)。

## 姓名标签

Cathy 正片介绍人物时使用两行姓名条，teaser 默认无。第一行为完整姓名，职务确认时可用 `<Company> <Role> ｜<Full Name>`；第二行为 `Twitter @完整handle`。不加 `Host/Guest` 眉题，不猜职位、雇主或账号，exact copy 优先；姓名卡与水印分别批准的大小写不得全局统一。

姓名行较大加粗、账号行较小，两行左对齐，底板包住内容，不留废弃眉题空行。按项目批准样式及长名字调整，不截名字或把账号缩成小字；避开脸和字幕。只改标签时保留原时段、转场、声音、字幕与封面，同步工程、composition 和实际烧录图集/MP4，查看各人物的导出帧。

## Cathy 个人水印

个人项目默认原文 `Twitter @CathyChang00`，不用于公司/客户项目；本轮文案、位置或关闭要求优先。位置、尺寸、颜色与 alpha 读取[固定预设](cathy-style.md)，复用批准透明资产。独立静态层覆盖首帧至末帧，包括 cold open、资料、章节与片尾，不加转场/音效，不被全屏层遮盖。

水印不替代姓名条、资料署名或 CTA。与字幕、账号、指标和人物操作冲突时调整其他布局，不临时挪动或隐藏水印。更新预览并烧入最终视频；仅加水印须保留批准时长、帧率、音频与同步。

先确认层时段、可见性和层级覆盖全片，再看首中末、资料、章节切换和最宽字幕的导出代表帧，核可读与碰撞；抽样不称逐帧验证。用 `ffprobe` 核时长、帧率和音轨。

## 字幕与资料的共同安全区

新增中文、双语或转画幅先读[中文字幕与转画幅](../../interview-subtitles-zh/SKILL.md)。Cathy 英文上、中文下，每种语言各一行；已有烧录英文时只加中文。英文字幕忠于原话，纠错留依据，按真实词级时间把长句拆为语义连续、零重叠的短字幕；其他未指定项目最多两行。

Cathy 字体、位置、宽度、底板与 alpha 统一读取预设 JSON，当前批准例外优先，不套旧画幅坐标。先预留字幕安全区，再排资料与姓名条；查看最宽句、连续分句、名字/账号与指标的导出帧及对比度。改字须同步烧录 PNG/图集、HTML 与 SRT，不能只改文稿。
