# Q2 Planning — notes on our OKR philosophy

OKRs = Objectives (qualitative, ambitious, time-bound) + Key Results (measurable outcomes, not tasks). We set them quarterly, keep 3–5 objectives with ~3 KRs each, and grade 0.0–1.0 — a 0.7 is healthy for a stretch goal. KRs measure outcomes, never activity. OKRs are decoupled from compensation to keep them ambitious. This doc explains the framework itself, not any product.
